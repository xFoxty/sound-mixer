# Sound Mixer / 声音调节器

一个面向 **Minecraft 26.2 + Fabric** 的客户端音效音量调节模组。

它把游戏里注册的每一种音效单独列出来，让你给每一种声音设置 **0% – 200%** 的音量：
TNT 爆炸、烈焰人发射火球、玩家/生物受伤、方块破坏、唱片音乐、按钮点击……都能单独调，
不再只能调“主音量 / 环境 / 生物”几个大类。

## 功能

- **逐音效调节**：每个 `SoundEvent` 一个 0% – 200% 滑块，0% 即静音。
- **完整中英文名称**：内置原版 1968 个音效的中英文名称数据库；中文界面全部显示中文名，英文界面全部显示英文名。搜索同时索引中英文名称，两种语言都能搜。
- **搜索**：按中文/英文音效名、完整 ID、路径关键字搜索，支持空格分隔多个关键词。
- **分类筛选**：全部 / 方块 / 实体 / 环境 / 音乐 / 界面 / 其他。
- **只看已修改**：快速找到自己动过的音效。
- **重置**：单个音效一键恢复 100%；“重置全部”带二次确认。
- **自动保存**：配置写入 `config/sound_mixer.json`，拖动结束、退出界面和定时自动保存。
- **Mod Menu 支持**：在 Mod Menu 的模组列表中直接打开配置界面。
- **快捷键**：默认 `K` 打开界面（可在“按键设置 → 杂项”中修改）。
- **兼容模组音效**：所有注册到 `minecraft:sound_event` 的音效都会自动出现在列表中，包括其他模组添加的音效。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 26.2 |
| Fabric Loader | 0.19.3 或更高 |
| Fabric API | 0.156.0+26.2 或更高 |
| Java | 25 |
| Mod Menu | 可选（用于在模组列表里打开配置） |

这是一个**纯客户端模组**。服务器不需要安装；它只改变你本地听到的声音，不会影响其他玩家。

## 安装

1. 安装 Fabric Loader 0.19.3+ 和 Fabric API 0.156.0+26.2 或更高。
2. 把 `sound-mixer-1.1.0.jar` 放进 `.minecraft/mods/`。
3. 可选：安装 Mod Menu。
4. 启动游戏，按 `K`，或在 Mod Menu 中点击 Sound Mixer 的配置按钮。

## 使用提示

- 原版 1968 个音效使用内置名称数据库：中文界面全中文，英文界面全英文；方块的破坏/放置/脚步等还会拼成“玄武岩：破坏”这种具体名称。
- 名称数据库位于 `assets/sound_mixer/sound_names.json`，同时供中英文搜索使用。
- 其他模组新增的音效会回退到 `sound_mixer.sound.<命名空间>.<路径>`、原版字幕或可读 ID；资源包可以补充翻译键覆盖。
- 搜索 `tnt`、`爆炸`、`blaze`、`烈焰人`、`hurt`、`受伤` 等关键词可快速定位常见音效。
- 每一行右侧滑块是音量，`1x` 按钮恢复 100%。
- 修改会立即作用于之后播放的声音；正在循环的声音会在下一次播放/刷新时使用新音量。
- 配置文件：`.minecraft/config/sound_mixer.json`。删除它即可恢复全部默认值。

## 从源码构建

需要 **JDK 25**（Minecraft 26.2 的最低 Java 版本）。

```bash
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

产物在 `build/libs/sound-mixer-1.1.0.jar`。

开发环境运行客户端：

```bash
./gradlew runClient
```

## 技术说明

- 使用 Fabric Loom `1.19.3`、Gradle `9.8.2`、Fabric Loader `0.19.3`、Fabric API `0.156.0+26.2` 构建，兼容更高的 26.2 版本。
- 音量控制在 `AbstractSoundInstance#getVolume()` 的返回值上做 Mixin 缩放，因此对一次性音效、循环音效、音乐和 UI 音效都生效。
- 原版名称数据库覆盖全部 1968 个 `SoundEvent`：字幕音效直接使用官方中英文，方块类音效拼成“方块名：动作”，无字幕的环境/音乐/唱片/UI 音效单独生成中英文名。
- 配置只保存非 100% 的条目，JSON 结构简单，便于手动编辑或备份。
- Mod Menu 是编译期可选依赖；未安装时不会加载相关类。
